# Problem Statement — Maintenance Friction

> Maintenance is the highest-frequency, highest-emotion interaction in the resident–manager relationship, and today it runs on phone tag, scattered texts, and manual triage. Residents don't know how to describe a problem or where it stands. Property managers act as human switchboards — re-keying requests, chasing vendors, and fielding "any update?" calls. Vendors arrive with incomplete information and make second trips. The result is slow resolution, high coordination labor per work order, and a maintenance experience that quietly erodes resident renewals and manager trust in the platform.
