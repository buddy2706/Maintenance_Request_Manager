# Rollout & Adoption Plan — Guided Maintenance Workflow

**Principle:** shipping the feature isn't the finish line — *confirmed recognized value in customer behavior* is. This plan owns the full lifecycle.

## 1. Internal enablement
- Trio demo + recorded walkthrough of every state and error flow.
- Support playbook: new statuses, common questions, escalation paths.
- CS enablement: per-account adoption view, the value narrative, how to run a design-partner account.
- Sales/marketing briefing on positioning (coordination labor removed).

## 2. Customer communication
- Design partners: co-design framing ("help us shape this"), direct trio access.
- Beta cohort: value-framed announcement + short "what changes for your team" guide + resident-facing copy templates managers can forward.
- GA: in-app announcement, changelog, webinar/office hours, one-pager for property managers to brief their residents.

## 3. Phased rollout
- **Phase 0 – Alpha:** 2–3 partners, one category, heavy instrumentation, weekly trio review.
- **Phase 1 – Beta:** more categories + accounts; compare metrics to each account's own baseline.
- **Phase 2 – GA (staged):** roll by portfolio size (smaller first), watching SLA/escalation load.
- **Gate between phases:** advance only if primary metrics move *and* guardrails (reopened rate, satisfaction) hold.

## 4. Measurement checkpoints
- Weekly (alpha/beta): leading indicators — intake completion, triage-ready %, vendor accept time.
- Bi-weekly: lagging — time-to-resolution, touches/WO, repeat-visit rate vs. baseline.
- Monthly: renewal/expansion signals — adoption %, status-contact volume, adoption↔renewal correlation.

## 5. How we confirm the solution landed
It landed when, per account: median time-to-resolution and manager touches/WO have dropped versus that account's own baseline; resident status-contacts have fallen; guardrails held; and adoption has crossed the usage threshold where customers describe it as *"I can't run maintenance without this."* At that point we hand off to CS with a value-realization summary per account and fold the learnings into the next opportunity (owner reporting, vendor performance) — closing the lifecycle loop.
